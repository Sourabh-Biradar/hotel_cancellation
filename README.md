#### Project : Hotel Cancellation Analysis   

Objective: To analyze booking data and identify the factors that contribute to cancellations to help hotels improve operational planning, optimize pricing strategies, and reduce revenue loss.

Shape of Dataset: 119,390 rows and 32 columns.  

Tools Used: Python, Pandas, Matplotlib, Seaborn, and Jupyter Notebook.
